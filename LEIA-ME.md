# Publicar o site corrigido

1. Extraia este ZIP.
2. Abra o repositório camilaandelias/casamento na branch usada pelo GitHub Pages.
3. Clique em Add file > Upload files.
4. Envie TODOS os arquivos extraídos diretamente na raiz do repositório e confirme em Commit changes.
5. Aguarde a publicação na aba Actions e abra https://camilaandelias.github.io/casamento/.

Todos os arquivos ficam juntos, sem subpastas. Envie os arquivos extraídos, não o ZIP nem a pasta que os contém.

Os caminhos das fotos e da fonte foram ajustados para essa estrutura. Os links de início usam ./ sem #inicio. Os demais links continuam navegando para suas seções.

Para editar os dados, use config.js. Para adicionar fotos, coloque-as junto de index.html e inclua o nome do arquivo na lista fotos de config.js.
